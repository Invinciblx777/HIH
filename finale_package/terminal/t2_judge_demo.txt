== 7. Residual risks (stated, not hidden) ==
  - a compromised broker or signing key can sign a false but consistent record; only a reviewer's independent
    terminal-hash note or countersignature (--require-countersignature) catches a key thief who replaces every
    retained copy, and only while the reviewer key is off the broker host
  - the host kernel and container runtime are shared and trusted (containers run as subordinate UIDs, not the
    key owner, but a kernel exploit can still reach the host user); hardware side channels are untested
  - the canary detector misses double encodings, ciphers, homoglyphs and paraphrase (single base64, hex, rot13,
    reversed, split and spelled-out forms are withheld since finale P4)
  - prompt-injection results show information-flow control, not model robustness
  - timing: 250 ms padding lowers one classifier's accuracy on the stub only; with a real model it leaks, and the
    real-model default is deadline release (no leak detected in 3 executions; not a proof of absence)
